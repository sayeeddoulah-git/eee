# Faculty website: Dr. Abul Barkat Mollah Sayeed Ud Doulah

All files sit at the top level of the repository. There are no folders.

| File | What it is |
| --- | --- |
| `content.js` | All website text. **This is the file you edit.** |
| `editor.html` | A form for adding or editing research topics with pictures. Open `https://YOUR-USERNAME.github.io/editor.html` |
| `obe-cep-training.html` | The OBE and CEP training module (you add this file: rename the module's `index.html` to this name before uploading). |
| `photo.jpg` | Profile photo. Replace it by uploading a new file with the same name. |
| `index.html`, `style.css` | Layout and navy design. Only change these for design changes. |

## Add a research topic with pictures
1. Open `https://YOUR-USERNAME.github.io/editor.html`.
2. Click **Add new research topic**, then fill in the title, summary and description, and add pictures.
3. Click **Download files**. You get `content.js` and the pictures, already resized for the web.
4. In the repository: **Add file → Upload files** → drag in all the downloaded files → **Commit changes**.

## Other edits
Open `content.js` on GitHub → pencil icon → edit → **Commit changes**. Instructions for publications, projects, gallery pictures and the CV are at the top of that file.

## Add the CV
Upload the PDF next to these files, then set `"cvPdf": "your-file.pdf"` in `content.js`. Remove personal phone numbers from the PDF first, because it will be public.
